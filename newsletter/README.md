# Newsletter tool – svet-pokoju.cz

Password-protected web app: pick a topic from the publication plan (built from the AKW keyword
analysis), a sale or seasonal campaign, or a custom brief → the app loads products live from
svet-pokoju.cz, Claude writes the copy → user edits text/products with a live preview → approved
e-mail is inserted into Ecomail as a **campaign draft** (never sent automatically).

## Stack
- Cloudflare Workers (free plan) + static assets in `public/` (vanilla JS, no build step)
- `src/index.ts` – API router; `src/auth.ts` – shared password + signed session cookie
- `src/shop.ts` – parses product cards from category/search pages on svet-pokoju.cz (cached 1 h)
- `src/ai.ts` – Claude (`claude-opus-5-5`, structured JSON output, server-side refusal fallback)
- `src/email.ts` – responsive HTML e-mail (Ecomail merge tags `*|WEBVERSION|*`, `*|UNSUB|*`, UTM links)
- `src/ecomail.ts` – Ecomail API v2 (`POST /campaigns` creates a draft)
- `src/plan.json` – publication plan, generated by `tools/build_plan.py`

## Publication plan
```bash
python3 tools/build_plan.py "<AKW export>.csv" --out src/plan.json
```
Topics, keyword regexes and product sources (category paths or `vyhledavani:<query>`) are defined at
the top of `tools/build_plan.py`.

## Catalogue (sitemap)
`tools/build_catalog.py` turns `https://www.svet-pokoju.cz/sitemap.xml` (≈ 32 MB, too big for the Workers free CPU
limit) into `site.json` (categories with real names, brands / collections / rooms, blog articles, info pages,
newly added products, plan coverage) and `products.json` (index for instant search). GitHub Actions
(`.github/workflows/update-feed.yml`, every 6 h) publishes it to GitHub Pages under `/newsletter/`; the worker
reads it from `CATALOG_URL` and falls back to the copy bundled in `public/data/`. New products are detected by
comparing with the previous run (`firstSeen`), because the sitemap has no lastmod.
```bash
python3 tools/build_catalog.py --out public/data --previous public/data   # refresh the bundled copy
```

## Local development
1. `npm install`
2. `cp .dev.vars.example .dev.vars` and fill in values
3. `npm run dev` → http://localhost:8787

## Deploy (Cloudflare)
```bash
npx wrangler login
npx wrangler secret put APP_PASSWORD
npx wrangler secret put SESSION_SECRET      # long random string
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put ECOMAIL_API_KEY     # once the Ecomail account exists
npm run deploy
```
Non-secret defaults (sender name/e-mail, default list id) are in `wrangler.jsonc` → `vars`.
The sender e-mail must be on a domain verified in Ecomail.

## Costs
Cloudflare Workers free plan (100k requests/day). Claude API is paid per use – one generated
e-mail is roughly 15–25k tokens (≈ 0.10–0.20 USD with Opus 5.5).

## Changelog (Historie změn)
Every user-visible change, fix or improvement **must** add an entry to `public/changelog.json`
(newest date first; `type`: `new` | `improve` | `fix`; text in Czech, written for the shop owner).
The app shows it in the footer → "Historie změn".

## Návod pro tým (public/navod.html)
Team guide at https://nl.svet-pokoju.workers.dev/navod (public, no password, `noindex`; never put the password in it).
Every change that alters what users see or do **must** also update `public/navod.html` in the same commit
(texts, buttons, steps, warnings) and bump the date in `#doc-updated`. Its "Poslední změny" section loads
`changelog.json` automatically. Linked from the app footer ("Návod") and the login screen.

## Hlas značky

Příběh, tón hlasu a povinná pravidla psaní (bez dlouhých pomlček a znaku „&“) jsou v `src/hlas-znacky.md`. AI ho čte při každém generování. Po úpravě souboru stačí aplikaci znovu nasadit (`npx wrangler deploy`).
